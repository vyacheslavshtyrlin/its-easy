# Download Speed CLI

Консольная утилита для простой проверки скорости скачивания по HTTP или HTTPS.
Она последовательно выполняет **10 запросов** к указанному адресу и каждый раз
дожидается полного тела ответа.

## Требования

- Node.js 20 или новее
- npm (нужен только для удобного запуска команд)

Сторонние зависимости не используются.

## Запуск

```bash
npm start -- https://example.com/large-image.jpg
```

Можно запустить файл напрямую:

```bash
node download-speed.js https://example.com/large-image.jpg
```

Пример результата:

```text
Запросов: 10
Среднее время запроса: 245.17 мс
Скачано всего: 52428800 байт (50.00 MiB)
Средняя скорость скачивания: 20.39 MiB/s
```

## Как считаются показатели

- **Время запроса** измеряется от начала запроса до полного чтения тела ответа,
  включая переходы по редиректам.
- **Среднее время запроса** — сумма времени всех запросов, делённая на 10.
- **Общий объём** — сумма байтов тел десяти конечных ответов. HTTP-заголовки,
  служебные данные протокола и тела промежуточных редиректов не учитываются.
- **Скорость скачивания** — общий объём, делённый на суммарное время всех
  запросов. Результат выводится в **MiB/s**: 1 MiB = 1 048 576 байт.

Скрипт запрашивает ответ без сжатия (`Accept-Encoding: identity`), чтобы объём
соответствовал фактически прочитанному телу. Поддерживается до пяти редиректов.
Таймаут одного запроса — 30 секунд. Ответы с HTTP-статусом вне диапазона
`200–299`, сетевые ошибки и неподдерживаемые протоколы завершают программу с
ненулевым кодом.
